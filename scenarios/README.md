# Final evaluation scenarios (H01–H06)

Put `customer_scenarios_for_final_evaluation.txt` **here**.

These are the six customer scenarios used for final judging. Per the challenge
rules, the answers to H01–H06 **must be generated by the assistant** (no manual
editing, no case-specific hard-coding) and **committed to the repository**.

## How to generate the committed answers

```bash
python run_evaluation.py scenarios/customer_scenarios_for_final_evaluation.txt
```

This runs every scenario through the exact same pipeline as the live chat and
writes one structured answer per scenario to `outputs/evaluation/`
(`H01.md … H06.md`). Commit those files to the repo.
