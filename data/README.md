# Knowledge base documents

Put your spectroscopy reference documents here (PDF, Word `.docx`, Excel
`.xlsx`, or `.txt` / `.md`), then run:

```bash
python ingest.py data/
```

to bulk-load them into the knowledge base. You can also upload documents
directly in the app's sidebar while it is running.

This folder is just a convenient default location — nothing is committed from
here except this README.
